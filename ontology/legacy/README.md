# Legacy Ontology Archive

These files preserve the original Phase 1 scaffold that used the
`https://example.local/ai-data-center-infrastructure#` namespace.

They are not part of the runtime ontology contract, are not loaded by
`SemanticValidationEngine`, and must not be imported by active modules, SHACL
shapes, queries, fixtures, or application code. The authoritative ontology is
the `urn:dcai:ontology:` module set in `ontology/modules/`.

The archive remains in source control solely for historical traceability.
